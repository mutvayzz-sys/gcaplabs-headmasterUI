# Product

## Register

product

## Users

People using Headmaster as a desktop AI work environment, including non-technical users configuring everyday preferences and technical operators connecting models, runtimes, tools, and specialist agents. They need to understand what is safe to change, complete setup without knowing internal architecture, and recover quickly when a connection fails.

## Product Purpose

Headmaster coordinates AI specialists, models, tools, memory, and scheduled work from one desktop application. Success means users can start useful work quickly, understand the system's current readiness, and change configuration without accidentally damaging the runtime.

## Brand Personality

Warm, meticulous, plain. The product should feel confident and quietly authoritative, with clear language and a small amount of polite, slightly amused character. It should not sound corporate, academic, or like infrastructure documentation.

## Anti-references

- Generic developer consoles that expose implementation terms as the primary information architecture.
- Dense settings pages where every field has equal visual weight.
- SaaS dashboards built from repeated cards, pills, and decorative status colors.
- Novel controls for standard preferences or configuration tasks.
- Interfaces that mix everyday preferences and destructive system configuration without a clear boundary.

## Design Principles

1. Organize around user intent, not internal subsystems.
2. Keep everyday preferences safe and obvious; isolate expert configuration behind a deliberate boundary.
3. Show system readiness and consequences before exposing raw configuration.
4. Use plain Headmaster vocabulary consistently across navigation, labels, help, and errors.
5. Preserve context, unsaved work, and recovery paths throughout configuration workflows.

## Accessibility & Inclusion

Target WCAG 2.2 AA. All settings must be keyboard operable, expose programmatic names and states, retain visible focus, support 200% text scaling, avoid color-only status communication, and respect reduced-motion preferences.
