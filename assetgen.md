# assetgen — gcaplabs-headmasterUI

Scope: GCAP-original media only. Excluded from this list (per scope decision): channel logos (`packages/desktop/src/renderer/assets/channel-logos/*` — Slack, Discord, Telegram, WeCom, Lark, DingTalk, WeiXin), AI-provider logos (`assets/logos/ai-major/*` — Claude, Gemini, Grok, DeepSeek, Mistral, OpenRouter, Perplexity, Groq, Cerebras), the `examples/` template extensions, and the entire vendored `hermeshq/` sub-project — those are third-party marks or a separately-maintained bundled project, not GCAP originals.

**Important finding — read before regenerating anything here:** this repo is a white-label fork of an upstream project ("AionUi"). `CLAUDE.md` explicitly bans shipping "AionUi" in UI-facing strings. But several of the assets below **still show the literal word "AionUi"** or still use its old smiley-mascot mark, unchanged from the fork:
- `resources/headmaster-banner-1.png` — README banner still reads "AionUi — Open Source Cowork with AI Agent"
- `packages/desktop/src/renderer/assets/themes/default-theme.png` (and likely its siblings) — theme preview thumbnail still shows the "AionUi" wordmark
- `resources/headmaster_logo_no_border.png`, `resources/headmaster_logo_black_bg.svg`, `packages/desktop/src/renderer/assets/logos/brand/headmaster.png` — despite the "headmaster" filename, this is the old AionUi triangle+dot+smile glyph, not a distinct Headmaster mark

By contrast, `resources/app.png` / `app.ico` / `app.icns` / `icon.png` (and the mobile/PWA copies of it) use a different mark from the leftover AionUi glyph: a forest-green hexagonal shield with a gold accent and three horizontal bars (reads as a stylized mortarboard/insignia).

**Correction: this shield has not actually been chosen as the Headmaster mark.** An earlier pass of this doc called it "the real, distinct Headmaster mark" and "the identity to build the rest of the brand around" — that overstated it. It's simply the icon file that happens to be sitting in `resources/app.png` today; nobody has confirmed it as the picked logo, the same way the octopus concept on `gcaplabs-site` was never actually chosen either. **Picking an actual company logo (GCAP Labs, the parent brand) and a separate product logo (Headmaster) is open, unresolved work** — see the priority note in `masterassets.md` / `mastertodo.md`. Two distinct marks make sense here: GCAP Labs is the company/parent brand across all products (site, console, docs, future products), while Headmaster is one product under it — conflating them into a single mark is likely wrong on purpose, not an oversight to fix later. Treat the shield below as one existing candidate/reference, not a locked answer, when writing any new prompt.

Also worth flagging separately: `resources/` contains ~20 additional PNGs (all with the same `Jun 12 19:12` import timestamp) that are unmodified upstream AionUi README assets — some referencing the *upstream* Chinese-community ecosystem (`linuxdo.png`, `packycode.png`, `openclawvia.png`, `wx-11.png`, `contactus-x.png`). These aren't GCAP originals and don't depict this product; they're prune candidates for the README rather than regen candidates, so they're omitted from the table below.

Brand reference for prompts: primary mark = forest green (~#1A4D2E) hexagonal shield, gold (~#C8A14A) accent bar, white interior with three horizontal green bars, on cream (~#FAF7F2) background — clean, flat, geometric, no gradients. This green matches `gcaplabs-site`'s `--accent` token exactly.

**Correction:** an earlier pass of this doc called the gold accent "not a documented token, just what one icon file uses." That was wrong — `docs/theming/gcap-brand-tokens.json` in this repo documents a full palette: paper `#f4f1ea`, ink `#1a1814`, primary `#1a4d2e`, **gold `#c9a96e`**, plus signal/moss/clay/warm secondary colors, a dark-mode set (primary `#74a981`, gold `#d4b77a`), and typography (display: Georgia serif, body: Inter, mono: JetBrains Mono). This is a real, applied system — confirmed live in `gcaplabs-console`'s `globals.css`/`branding.ts`. `gcaplabs-site` has not adopted it yet (see `gcaplabs-docs/assetgen.md` for that gap). Prompts below can treat gold as canon, not a guess.

**What this app actually is, for anyone screenshotting it later:** Headmaster is a real white-label of the open-source **Hermes Agent** (Nous Research, Apache-2.0/MIT) — a local-first desktop app, not a hosted SaaS. Its real, shipped navigation is **Chat, Memory, Agents ("Specialists"), Automations, Kanban, Deliverables, Settings**, plus a **Team/"Council"** section and a conversation-history list; also present but less prominent: **Activity, Documents, Workflows, Browser**. `gcaplabs-site`'s marketing imagery has, until now, been built around an invented dashboard (KPI-card Dashboard, Approvals queue, Analytics, "Model Stack") that doesn't match this list — once the AionUi→Headmaster rebrand below is done, real screenshots should be captured from the actual nav, not the site's old mockups.

## Notes on what's intentionally omitted
- `examples/**` (extension template covers/icons) — boilerplate scaffolding for third-party extension authors, not GCAP branding.
- `hermeshq/**` (docs media, frontend assets, Spanish-language icon set) — a bundled, separately-maintained sub-project; regenerate within its own repo/process if in scope, not here.
- `packages/desktop/src/renderer/assets/channel-logos/*` and `assets/logos/ai-major/*` — official third-party brand marks (Slack, Discord, Telegram, Claude, Gemini, etc.) that must stay accurate to the real vendor, not AI-generated equivalents.
- `resources/{ai-assistants-experts,alart-task,app_dev,assitants,bannerimage,bug-report-button,contactus-x,file_generation_preview,homepage,linuxdo,llm_newapi,multi-model,"offica-ai BANNER-function",openclawvia,packycode,"remote-telegram copy",remote-telegram,remote,screenshot_1,screenshot_2,"webui banner",webui-remote-example,webui-remote,wx-11}.png` — unmodified upstream AionUi README screenshots/banners (all imported in one batch); several reference the upstream project's own Chinese-community ecosystem and don't depict this product at all. Recommend pruning these from the README rather than spending regen budget on them.
